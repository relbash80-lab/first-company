# First Company

منصة SaaS لإدارة شركات استيراد السيارات، تعمل على Neon Postgres وNeon Auth وData API، وتدعم العربية والإنجليزية.

## إصدار 1.1.3 — كشف حساب

- أصبح الاسم الظاهر للقسم المالي «كشف حساب» بالعربية و`Account Statement` بالإنجليزية.
- التغيير اسمي فقط؛ وظائف الفواتير والإيصالات والتحصيل والأرصدة لم تتغير.

## إصدار 1.1.2 — انتهاء الجلسة عند الخمول

- تُغلق الجلسة تلقائيًا بعد 10 دقائق دون نشاط لحماية حساب المشترك.
- تتجدد المهلة بالحركة أو الكتابة أو اللمس أو التمرير، وتتزامن بين تبويبات المنصة.
- تظهر للمستخدم رسالة سبب الخروج عند عودته إلى صفحة تسجيل الدخول.

## إصدار 1.1.1 — مسودات السيارات

- جميع حقول إضافة السيارة اختيارية، ويمكن حفظ سجل فارغ وإكماله لاحقًا.
- يمكن إدخال VIN جزئيًا ثم تعديله؛ ويُمنع التكرار داخل الشركة عند اكتمال 17 خانة.
- المسودة الفارغة لا تنشئ عمولة، وتظهر في المركز باسم «سيارة غير مكتملة».
- ترحيل قاعدة البيانات موجود في `neon/migrations/20260829004000_vehicle_drafts.sql`، والتحقق مضاف إلى اختبار `neon/tests/saas-control-center-smoke.sql`.

## إصدار 1.1 — مركز تحكم SaaS

- مراقبة شهرية للمستخدمين النشطين والجلسات والعمليات والأجهزة دون حفظ IP الخام.
- كتالوج ميزات وحدود لكل باقة مع فرضها من PostgreSQL.
- إدارة أسعار شهرية وسنوية بالدينار الليبي مع سجل تاريخي للأسعار.
- لوحة مالك منصة للمشتركين والاستخدام والمدفوعات وسجل التدقيق والإصدارات.
- سجل إصدارات ظاهر للمشتركين على المسار `/updates`.
- تحديث ذكي يتوقف عند إخفاء التبويب لتقليل استهلاك Neon.
- تقسيم حزم الصفحات وتحسين لوحة الإدارة للهاتف والتابلت والحاسوب.

ترحيل الإصدار موجود في `neon/migrations/20260829002000_saas_control_center.sql`، واختبار PostgreSQL المحلي في `neon/tests/saas-control-center-smoke.sql`.

## مراقبة تكلفة Neon

تتضمن لوحة مالك المنصة تبويب **تكلفة Neon** لحساب التكلفة الشهرية التقريبية من الاستهلاك الفعلي:

- المجاني: حتى 100 CU-hour و0.5GB تخزين و5GB نقل عام لكل مشروع.
- Launch: الحوسبة `0.106$ × CU-hours` والتخزين `0.35$ × GB-month` وسجل الاستعادة `0.20$ × GB-month`، والنقل العام بعد 100GB بسعر `0.10$ × GB`.
- Scale: الحوسبة `0.222$ × CU-hours` مع مزايا مؤسسية مثل SLA والشبكة الخاصة والاحتفاظ الأطول بالسجلات.
- عدد المستخدمين وحده لا يحدد الفاتورة؛ القرار يعتمد على ساعات تشغيل الحوسبة وحجم البيانات والنقل. تُراجع أرقام لوحة Neon شهريًا وتدخل في الحاسبة.

الأسعار قابلة للتغيير؛ راجع دائمًا [صفحة Neon الرسمية للأسعار](https://neon.com/pricing) قبل قرار الترقية.

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env.local`.
2. ضع عنواني `VITE_NEON_AUTH_URL` و`VITE_NEON_DATA_API_URL` من لوحة Neon.
3. شغّل `npm install` ثم `npm run dev`.

لا تضع سلسلة اتصال PostgreSQL أو أي مفتاح خادمي داخل متغيرات Vite؛ العنوانان المطلوبان عامّان، والحماية الفعلية تُفرض بسياسات RLS.
